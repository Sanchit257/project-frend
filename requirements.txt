# System packages (install once with apt):
#   sudo apt install espeak-ng ffmpeg
#     espeak-ng    -> offline voice used by pyttsx3 (last-resort fallback)
#     ffmpeg       -> provides ffplay, which plays gTTS mp3s to the AirPods
#   pw-cat / pw-record (Cartesia playback and mic capture, including the
#   AirPods mic) ship with PipeWire, which Raspberry Pi OS already uses.
#   For the AirPods mic, also run once:  sudo ./setup_airpods_mic.sh
#
# Not used on purpose:
#   pyaudio / sounddevice - PortAudio only sees the Pi's raw ALSA devices,
#               not the Bluetooth (AirPods) speaker and mic that PipeWire manages.
#   runpod    - that SDK is for writing workers that run *on* Runpod. The
#               glasses only call the endpoint's HTTP API, so `requests` is
#               enough and keeps the install small.
